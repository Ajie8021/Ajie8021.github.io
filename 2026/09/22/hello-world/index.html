# 踩过的坑

在安装过程中难免会遇到一些问题，我罗列一下我遇到的问题以及解决方法，可供参考：

# YAML 缩进错误（多次）

现象：

$ YAMLException: bad indentation / can not read a block mapping entry

原因：

  • deploy: 被注释掉，type/repository/branch 成了孤儿缩进;
  • keywords:program 冒号后没空格;
  • 混用 Tab 和空格

解决：

  • 冒号后必须加空格：keywords: program;
  • 统一用空格缩进，deploy: 顶格;
# 渲染器不兼容（SXEC 104）

现象：

$ hexo-renderer-multi-next-markdown-it is not supported in ShokaX 0.5.2 and above,please use hexo-renderer-aether instead.

原因：ShokaX 0.5.2+ 要求用 hexo-renderer-aether，旧渲染器还在。

解决：

npm uninstall hexo-renderer-multi-next-markdown-it
npm uninstall hexo-renderer-multi-markdown-it
npm install hexo-renderer-aether --save

注意有两个旧渲染器，都要卸掉。

# 高亮引擎冲突（SXEC 101）

现象：

$ Highlight.js or Prismjs enabled. The code block will render incomplete.

原因：ShokaX 自带代码高亮，与主目录下的_config.yml冲突。

解决：
在 _config.yml 里将高光全部关闭：

syntax_highlighter:        # 设为空，或直接删掉这一行
highlight.enable: false
prismjs.enable: false
# image_list 报错

现象：
Hexo 启动/生成页面时报错：

$ image_list must have at least 6 items

涉及主题：node_modules/hexo-theme-shokax

原因：
ShokaX 首页封面配置启用了随机封面：

homeConfig:
  coverConfig:
    enableCover: true

而主题要求 image_list 至少包含 6 张图片。

解决方法：
在 _config.yml 中配置至少 6 个封面：

image_list:
  - /images/cover1.jpg
  - /images/cover2.jpg
  - /images/cover3.jpg
  - /images/cover4.jpg
  - /images/cover5.jpg
  - /images/cover6.jpg

并确保这些图片实际存在于：source/images/

# 音乐播放器报错

现象：
页面加载 JavaScript 时出现类似：

$ d.audio.forEach is not a function

原因：

ShokaX 的播放器代码会对 audio 配置执行：

audio.forEach(...)

当配置中的 audio 为空值、格式不正确或者没有按照数组处理时，就可能导致这个问题。

解决方法：

关闭播放器功能，将audio:改成audio: [],同时关闭播放器：

modules:
  player: false

也可以选择添加音乐。
